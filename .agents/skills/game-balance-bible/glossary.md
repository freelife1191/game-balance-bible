# 용어집

영문 약어 뒤에 한국어 용어를 가나다순으로 배치한다. 각 항목은 책의 용법을 스킬이 짧게 요약한 것이다(스킬 정리). 위치가 붙은 정의만 원문 서술을 옮긴 것이며, 상세 정의와 조건은 해당 장을 읽는다.

**AI** — 3.4절의 인공지능. 모든 NPC의 속성을 정량화하는 기본 응용과, 고착 지점·세계 번영과 유저 매칭 같은 고급 응용으로 나눠 다룬다(인쇄 88–89 / PDF 116–117). 고착 지점은 인쇄 93쪽(PDF 121)에서, 세계 번영과 유저 매칭은 인쇄 95쪽(PDF 123)에서 다룬다. NPC의 행동 패턴 설계는 다루지 않는다. (3장)

**ARPPU** — 기간 결제액/과금 유저 수. (6장)

**ARPU** — 기간 결제액/활성 유저 수. (6장)

**CHURN** — 해당 주기의 이탈 유저 비율. (6장)

**CPA** — 획득 기준을 고정한 유저 1명 확보 비용. (6장)

**I/O 구조** — 생산·유통·소비 입출력의 연결. (4장)

**LTV** — 유저 생애주기 가치. 책의 단순 근사에는 가정이 필요하다. (6장)

**PR** — 과금 유저 수/활성 유저 수. (6장)

**가성비** — 비용 대비 성장·플레이 수익. (4장)

**가치 체계** — 화폐·자원·능력치를 공통 기준으로 비교하는 구조. (4장)

**게임의 3요소** — 넓은 의미로는 게임 테마·게임 아트·게임의 깊이, 좁은 의미로는 게임의 넓이·깊이·난이도다. 책은 유저 관점과 기획 관점에서 좁은 의미를 다룬다(인쇄 18 / PDF 46). (2장)

**계획경제** — 유저 간 거래를 허용하되 거래의 종류·가격·화폐 유형 등을 적절히 유도하고 규제하는 경제(인쇄 112 / PDF 142). (4장)

**계획 생산** — 모델에 사전 정의한 자원 생산. (4·5장)

**능력치 정량화** — 성장 구축·분할·세분화로 속성 가치를 계산. (3장)

**등가 전투력** — 속성별 가치를 환산한 전투력. (3장)

**란체스터 법칙** — 특정 전투 가정에서 개체 성능과 수량을 비교하는 법칙. (3·5장)

**리듬감** — 규칙에 맞게 주기적으로 변화하는 운동 방식에서 생기는 미적 느낌. 게임에서는 스토리·성장·전투 과정의 리듬감이 있다(인쇄 226 / PDF 256). (7장)

**모듈화** — 게임 내 기능·플레이·성장의 수치 구조를 독립 설계하고 집중 관리하는 방식. 핵심은 모든 수치를 모델링하는 것이다(인쇄 239 / PDF 269). (8장)

**몰입감** — 활동에 깊이 집중하는 경험. 게임에서는 대부분 리듬감과 의례감이 교차해 생기는 심리 변화를 뜻한다(인쇄 230 / PDF 260). (7장)

**보물상자** — 고정 또는 랜덤 결과로 자원을 공급하는 매개체(인쇄 126 / PDF 156). (4장)

**블랙닷 구조 표** — 요소 사이의 연결 유무를 행렬로 표시한 표. (4장)

**생산 모델** — 고정·랜덤 생산과 분배로 보상을 정하는 모델. (4장)

**생존 비율** — 유저 생존 턴/몬스터 생존 턴. (5장)

**성장 모듈 / 육성 모듈** — 옮긴이 주에 따르면 원서는 두 용어를 정의·구분하지 않았으므로 같은 의미로 봐도 된다. 반면 저자는 ‘성장 검증’과 ‘육성 검증’은 구분해 썼다(인쇄 3 / PDF 31). 다만 5장 도입부는 세 과정을 경제 검증, 성장 검증, 전투 검증이라 부르고(인쇄 179 / PDF 209), 그중 둘째인 5.2절의 제목은 ‘육성 검증’이다(인쇄 185 / PDF 215). (1장)

**성장 벤치마크** — 다른 육성을 연결하는 기준 레벨·성장축. (3·5장)

**성장 분할** — 전체 성장 예산을 시스템별로 배분. (3장)

**성장 세분화** — 시스템 성장의 레벨·등급별 세부 배분. (3장)

**성장의 세분성** — 7장에서 성장 간격을 가리키는 말. 세분성이 크면 성장 간격이 길고 작으면 짧다(인쇄 227 / PDF 257). 3장의 성장 입상도와 같은 성장 간격 개념이다(스킬 정리). (7장)

**성장 입상도** — 매번 업그레이드하는 시간 간격(성장 간격). 세분화에서 곡선 선택의 기준이 된다(인쇄 79·84 / PDF 107·112). (3장)

**세계 번영과 유저 매칭** — 가상 유저 캐릭터로 팀원·상대·상호작용을 보완하는 AI 고급 응용. (3장)

**소비 모델** — 성장 모듈 소비를 중심으로 필요한 자원량을 정하는 모델. 소비 루트는 성장 모듈·플레이 모듈·기타 모듈 소비로 나뉜다(인쇄 137 / PDF 167). (4장)

**속성 변환 공식** — 총속성을 전투 효용·확률로 변환하는 방식. (3장)

**속성 총합 공식** — 육성 루트별 속성 보너스의 합산 방식. (3장)

**수익화 포지셔닝** — 경험·성장·기능·화폐 결제의 역할 선택. (6장)

**시장경제** — 유저 생산물의 거래·가격 형성을 허용하는 경제. (4장)

**원탁 이론 알고리즘** — 한 추첨 구간에 전투 결과를 배치하는 판정. (3장)

**의례감** — 과장되지만 실제적인 표현 형태. 과정은 과장되고 보상은 실제적이며, 주로 성장 과정과 플레이에서 나타난다(인쇄 229 / PDF 259). (7장)

**잔여 비율** — (생산−소비)/소비. 소비가 0이면 정의되지 않는다. (5장)

**잔여 자원** — 같은 기간의 누적 생산−누적 소비. (5장)

**추가 생산** — 이벤트·상점·퀘스트·업적·보물상자처럼 운영 중 늘어나는 보상. 원문 표 5.1은 이벤트·상점을 계획 생산 열에 두어 분류가 엇갈린다(인쇄 181 / PDF 211). (5장)

**충전 검증** — 실제 화폐 상품 구매를 유저군별 집계. (6장)

**타깃 게임** — 구조와 경험 설계의 비교 기준으로 고른 게임. 같은 장르·테마의 경쟁 게임이거나 비슷한 부분이 있는 게임일 수 있다(인쇄 3 / PDF 31). 1장 본문(인쇄 3 / PDF 31)과 찾아보기(인쇄 258 / PDF 288)는 ‘타깃 제품’으로 쓴다. (2장)

**퍼지 매칭** — 누적값 이하에서 도달 가능한 최대 구간 조회. (5장)

**폐쇄경제** — 유저 간 자원 거래가 없는 경제. (4장)

**확률론 알고리즘** — 결과를 정해진 순서로 개별 확률 판정. (3장)
