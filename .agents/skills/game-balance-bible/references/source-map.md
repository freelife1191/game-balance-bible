# 원문 근거와 추출 범위

> 이 파일은 스킬을 만들 때의 원문 대조 기록과 쪽 대응표다(스킬 정리). 개별 주장의 근거는 장 파일에서 위치가 붙은 문장을 따른다.

## 서지와 변환 설정

- 책: 《게임 밸런스 수치 기획 바이블》, 위안자오양 지음, 권유라 옮김, 제이펍, 한국어판 2024년.
- 생성일: 2026-10-12. 프로젝트 범위, 한국어, 실무 적용·학습·장별 참고를 함께 지원한다.
- 입력: 제작 프로젝트에 있던 원문 PDF(아래 SHA-256). 설치한 스킬에는 원문이 없는 것이 정상이며, 답변할 때 원문 파일을 찾지 않는다. 원문 대조가 필요하면 아래 쪽수로 확인할 위치를 안내한다.
- PDF 전체 290쪽. 본문 장은 8개이며, 머리말 등 앞부분·후기·색인·표지까지 장으로 세지 않는다. 다만 머리말(인쇄 xxv / PDF 27)의 장별 읽기 안내와 8장 소개는 SKILL.md와 8장에서, 후기의 수치 기획자 역할은 1장에서 인용한다.
- SHA-256: `db8068221feed05d1f23e6e8de9cdc6d8614c6f401353e96048764e1df42c019`.
- 추출 요청: technical. 실제 추출: Docling 미설치로 pdftotext 대체 사용. 표·수식의 배열과 OCR 기호에는 오류가 있을 수 있다.
- 스킬은 원문을 그대로 옮긴 것이 아니라 판단 규칙과 개념을 재구성한 학습 자료다. 긴 원문 문장과 전체 표는 복제하지 않는다.

표의 범위는 본문이 있는 마지막 쪽까지다.

- 3장 끝에는 인쇄 102–103쪽이 중복 스캔되어(PDF 130–131과 132–133) PDF 쪽수와 인쇄 쪽수의 차이가 이후 30으로 바뀐다.
- 4장에서는 인쇄 155쪽이 스캔에 없다(인쇄 154 / PDF 184 다음 쪽이 인쇄 156 / PDF 185). 인쇄 157쪽은 PDF 186과 187에 두 번 스캔됐다. 그래서 PDF 185–186은 차이가 29이고 PDF 187부터 다시 30이다.
- 인쇄 155쪽의 내용은 이 스킬에 반영되지 않았다. 인쇄 154쪽이 표 4.24 중간에서 끝나고 인쇄 156쪽이 문장 중간에서 시작하므로, 빠진 쪽은 표 4.24 뒷부분과 랜덤 생산 도입부로 추정한다(스킬 정리).
- 정리하면 PDF 29–131은 인쇄+28, PDF 132–184는 +30, PDF 185–186은 +29, PDF 187–288은 +30이다. 장 파일의 `(인쇄 N / PDF M)` 위치 쌍은 이 대응을 따른다.
- PDF 134, 208, 234, 254, 268쪽은 빈 장 경계 페이지다. 중복과 빈 페이지는 별도 장이나 추가 근거로 세지 않는다.
- 목차는 PDF 7–9쪽에서 직접 확인했다. 추출기의 61개 장 탐지와 목차 미탐지는 OCR 자동 분류 결과이며 이 스킬의 목차 기준으로 사용하지 않았다.

## 근거 사용 기준

- 장 파일에 제시된 예시는 책 예시의 압축 재구성 또는 설명용 새 가정으로 표시한다. 후자를 책의 실제 데이터로 인용하지 않는다.
- 계산할 때 변수 의미, 단위, 기간, 퍼센트 표기를 먼저 확인한다. 원문 기호가 흐릿했던 곳은 아래의 이미지 대조 기록을 따른다. 기록이 없는 기호는 단정하지 않고 사용자에게 확인할 원문 위치를 안내한다.
- 페이지 이미지를 전부 판독한 것은 아니다. 일부 핵심 수식·표만 시각 대조했으므로 이미지에만 존재하는 도식·그래프·정보의 완전한 보존을 보장하지 않는다.
- 게임 사례의 수치와 결제 전략은 책 집필 당시 사례다. 다른 게임에 쓸 때 장르, 성장 주기, 대상 유저와 실제 플레이 검증에 맞춰 재설정한다.
- 외부 법률·정책·현재 시장 통계는 이 책의 범위 밖이다. 책의 역사적 사례로 현재의 사실을 단정하지 않는다.

## 추가 원문 대조 기록

사용자의 원문 재확인 요청에 따라 1~8장 표·그림을 다시 탐색하고, 도식의 구조·축·라벨과 계산에 필요한 표·각주를 렌더 이미지로 대조했다. 실제 시각 확인 페이지와 표/그림 목록은 이 스킬을 만든 저장소의 `output/skill-review/source-recheck-audit.json`에 있다(스킬 폴더 밖이며 설치본에는 없을 수 있다. 답변 중에는 찾지 않는다). 파일을 렌더하기만 한 페이지는 시각 확인으로 세지 않는다.

- 1~2장: 전략/전투/I/O 관계, 장르 관계도, 바틀·커시·인구통계학적 게임 설계(DGD1) 축, 플레이 분포·해금·역추론 도식을 확인했다. 비율·시간은 사례이며 사람을 고정 분류하는 기준으로 쓰지 않는다.
- 3장: 속성 성장·계층 분할·누적 강화·유저 템플릿·직업 가치·NPC 난이도 표를 다시 확인했다. 표 3.15는 표 3.7의 힐러 성장을 데이터 소스로 삼는다고 하면서 체력 4,800(공격력·방어력·체력 1:1:8)을 싣고, 표 3.5·3.7의 체력은 6,000(1:1:10)이다(인쇄 80 / PDF 108). 원문 내부 불일치이므로 표마다 그 표의 입력으로 재현한다.
- 4장: 경제모델·I/O·중간 변환·소비·가성비 그래프의 의미와 과금의 깊이를 확인했다. 표 4.14의 시간 1.02는 텍스트의 102와 구별한다.
- 5장: 성장/소비 조회의 레벨 의미와 표 5.15 각주, 네 성장·잔여 그래프를 확인했다. 표별 예시가 완전히 일치한다고 가정하지 않는다.
- 6장: 표 6.1과 본문 LTV, 상품 구매 열·그룹별 합산·차액을 다시 확인했다.
- 7~8장: 이중축·몰입 그래프·단계 목표표·모듈 연결망·성유물 풀과 초기/누적 성장 산식을 확인했다. 그래프 전체 좌표와 미기재 확률을 추정하지 않는다.

## 실무 적용을 위해 추가한 계산 조건

타격 횟수의 올림과 첫 타격 시점, 피해 하한·분모 0 처리, 공유 재화의 총량 제약, 비선형식의 버프 단계 구분은 책의 모델을 프로젝트에 적용할 때의 보완 지침이다. 새 설명용 수치와 함께 표시하며, 책이 특정 구현 정책을 강제한 것으로 인용하지 않는다. 원문 LTV의 단어와 예시 표의 불일치는 확인된 상태로 남겨 둔다.

## 재검수에서 확인한 원문 표현과 재현 조건

- 인쇄 59 / PDF 87: 곱셈식의 `1-R`은 피해 잔존 배율이다. 원문이 이를 감소율로 부르는 문장은 따르지 않고, 감소율 `R`과 구별한다.
- 인쇄 138·142 / PDF 168·172: 소비식의 레벨 명칭과 강화 표의 레벨 축이 혼용되어 있다. 캐릭터 레벨과 강화 레벨을 분리하고 대응 관계를 입력한다. 표 4.14는 그 대응·반올림 조건이 충분히 제시되지 않아 공개된 식만으로 모든 값을 유일하게 재현할 수 없다.
- 인쇄 166–167 / PDF 196–197: 본문 예시의 공격력·체력 단가와 표 4.35의 단가는 10배 차이가 난다. 표 4.36의 합계 1,782를 재현하려면 표 4.35의 공격력 1·방어력 1·체력 0.1을 사용한다. 본문 예시의 공격력 10·체력 1을 이 표 계산에 섞지 않는다. 표 4.12·4.17의 전투력 가치(레벨 1은 90, 합계 17,820)는 본문 단가 기준이라 표 4.36(9, 1,782)과 10배 차이가 난다(인쇄 140·145 / PDF 170·175). 두 표의 비율을 섞어 비교하지 않는다.
- 인쇄 183 / PDF 213: 표 5.3의 100일 총생산 표시 222,168,267은 잔여량·소비량과 맞지 않는다. 표 5.1(인쇄 181 / PDF 211)의 22,216,827은 `11,747,361+10,469,466`과 일치하며 잔여 비율 약 112%도 재현한다. 스킬의 해석: 정합되는 값으로 읽고 오기값은 사용하지 않는다.
- 인쇄 127 / PDF 157: 원문 상자 기대가치 표시 7.1→7.3과 정밀 재계산 7.10→7.32는 표시 자릿수의 차이다. 원문값과 계산값을 구분해 기록한다.
