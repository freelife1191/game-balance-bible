## 근거 사용 기준

- 장 파일에 제시된 예시는 책 예시의 압축 재구성 또는 설명용 새 가정으로 표시한다. 후자를 책의 실제 데이터로 인용하지 않는다.
- 계산할 때 변수 의미, 단위, 기간, 퍼센트 표기를 먼저 확인한다. 원문 기호가 흐릿하면 페이지 이미지와 표의 계산 결과를 함께 확인한다.
- 페이지 이미지를 전부 판독한 것은 아니다. 일부 핵심 수식·표만 시각 대조했으므로 이미지에만 존재하는 도식·그래프·정보의 완전한 보존을 보장하지 않는다.
- 게임 사례의 수치와 결제 전략은 책 집필 당시 사례다. 다른 게임에 쓸 때 장르, 성장 주기, 대상 이용자와 실제 플레이 검증에 맞춰 재설정한다.
- 외부 법률·정책·현재 시장 통계는 이 책의 범위 밖이다. 책의 역사적 사례로 현재의 사실을 단정하지 않는다.

## 추가 원문 대조 기록

사용자의 원문 재확인 요청에 따라 1–8장 표·그림을 다시 탐색하고, 도식의 구조·축·라벨과 계산에 필요한 표·각주를 렌더 이미지로 대조했다. 실제 시각 확인 페이지와 표/그림 인벤토리는 [재확인 감사 기록](../../../../output/skill-review/source-recheck-audit.json)에 기록한다. 파일을 렌더하기만 한 페이지는 시각 확인으로 세지 않는다.

- 1–2장: 전략/전투/I/O 관계, 장르 관계도, 바틀·커시·DGD1 축, 플레이 분포·해금·역추론 도식 확인. 비율·시간은 사례이며 사람을 고정 분류하는 기준으로 쓰지 않는다.
- 3장: 속성 성장·계층 분할·누적 강화·유저 템플릿·직업 가치·NPC 난이도 표를 다시 확인했다. 표3.5의 HP6,000과 표3.30의 HP4,800은 서로 다른 사례 입력으로 유지한다.
- 4장: 경제모델·I/O·중간 변환·소비·가성비 그래프의 의미와 과금 깊이를 확인했다. 표4.14의 시간1.02는 텍스트의102와 구별한다.
- 5장: 성장/소비 조회의 레벨 의미와 표5.15 각주, 네 성장·잔여 그래프를 확인했다. 표별 예시가 완전히 일치한다고 가정하지 않는다.
- 6장: 표6.1과 본문 LTV, 상품 구매 열·그룹별 합산·차액을 다시 확인했다.
- 7–8장: 이중축·몰입 그래프·단계 목표표·모듈 연결망·성유물 풀과 초기/누적 성장 산식을 확인했다. 그래프 전체 좌표와 미기재 확률을 추정하지 않는다.

- PDF168·172 / 인쇄138·142: 소비식의 레벨 명칭과 강화 표의 레벨 축이 혼용되어 있다. 캐릭터 레벨과 강화 레벨을 분리하고 대응 관계를 입력한다. 표4.14는 그 대응·반올림 조건이 충분히 제시되지 않아 공개된 식만으로 모든 값을 유일하게 재현할 수 없다.
- PDF196–197 / 인쇄166–167: 본문 예시의 공격력·체력 단가와 표4.35의 단가는 10배 차이가 난다. 표4.36의 합계1,782를 재현하려면 표4.35의 공격력1·방어력1·체력0.1을 사용한다. 본문 예시의 공격력10·체력1을 이 표 계산에 섞지 않는다.
- PDF213 / 인쇄183: 표5.3의 100일 총생산 표시222,168,267은 잔여량·소비량과 맞지 않는다. 표5.1(PDF211)의22,216,827은 `11,747,361+10,469,466`과 일치하며 잔여 비율 약112%도 재현한다. 스킬은 정합되는 값으로 해석하고 오기값을 사용하지 않는다.
- PDF157 / 인쇄127: 원문 상자 기대가치 표시7.1→7.3과 정밀 재계산7.10→7.32는 표시 자릿수의 차이다. 원문값과 계산값을 구분해 기록한다.

스킬에 포함된 수치·공식·프레임워크를 다시 대조했다. 이 검수는 책 전체에 있는 모든 표·이미지의 오류를 판정한 전면 교정은 아니다. 계산 근거와 확인 범위는 프로젝트의 `output/skill-review` 감사 보고서에 보존한다.
