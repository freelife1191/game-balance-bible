# 질문별 자료 지도

> 질문에 맞는 자료를 고르기 위한 스킬의 탐색 색인이다(스킬 정리). 행의 짧은 설명만으로 상세 조건을 단정하지 말고, 연결된 파일의 해당 절 전체를 읽는다.

`references/`의 이름이나 파일 개수보다 **질문 → 상세 설명 → 계산 계약 → 근거**가 연결되는지가 중요하다. 아래에서 질문에 해당하는 행만 읽는다. 책의 프레임워크와 공식은 연결된 파일에 유지하며 여기에는 복제하지 않는다.

## 근거를 사용하는 순서

1. 관련 장에서 개념·판단 이유를 읽고, 수치 계산이면 연결된 공식·조건까지 읽는다. 5·6장의 검증식은 장 파일에 있으며 별도 공식 파일이 없다는 이유로 누락으로 판단하지 않는다.
2. 출처가 필요하면 [소절별 반영 지도](source-map.md#소절별-반영-지도)에서 인쇄/PDF 쪽을 찾고, 오류·불일치 메모를 확인한다.
3. `책 예시`, `책 예시의 재계산`, `실무 보완`, `설명용 가정`을 구별한다. 원문 수치를 새 게임의 기본값으로 제시하지 않는다.
4. 저장된 자료로 확인할 수 없는 표·그림의 세부를 묻는 경우, 원문이 있으면 해당 쪽만 재확인한다. 원문이 없으면 확인 범위와 불확실한 항목을 밝힌다.
