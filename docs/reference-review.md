## 판단

**8개 장의 주요 개념·설계 절차·검증 흐름은 반영돼 있다.** 다만 기존 자료는 몇 가지 하위 주제를 생략했고, 레퍼런스의 세부 위치와 원문 소절의 연결이 약했다. 이번에 이를 보완했다. 이 판단은 원문 전체의 모든 표·그림·수치가 완전히 보존됐다는 뜻은 아니다.

별도의 `references/` 폴더가 모든 스킬에 필수인 것은 아니다. 이 스킬은 `chapters/`에 장별 판단·예시를, `references/`에 상세 산식·조건·근거·탐색 경로를 둔다. 특히 5·6장의 검증식은 장 파일에 있으므로 별도 공식 파일로 중복 복사하지 않았다.

## 읽기 경로

- 개념·학습: `SKILL.md`의 주제색인 → 해당 장 → 필요한 계산·근거 자료.
- 실무 계산: 질문별 자료 지도 → 관련 장·공식 절 → 변수·단위·조건·원문 불일치 확인 → 계산.
- 출처·범위: 원문 지도 → 소절별 페이지·반영 수준 → 이미지 대조 목록·오류 메모.
- 빠른 판단: 치트시트; 용어: 용어집; 실행 순서: 패턴. 상세 공식은 해당 레퍼런스를 읽는다.

### 원문에 남아 있는 불일치

- 화폐비율은 본문1:10:100과 표/후속식1:10:10이 다르다(PDF195).
- 생산 표의 루트별 기간·누적 총합, 같은 경험치에 대한 레벨 예시, 성장 그래프 범례가 서로 정합되지 않는 부분이 있다(PDF211·217–218·223).
- 표5.15의‘생존 비율’은 각주상 양쪽1회 피해량의 비율이며 해당 피해 산식도 명시되지 않는다(PDF229–230).
- LTV 본문의 결제율 표현은 표 산술의 ARPU와 다르고, 손익분기월 열의 산식은 제시되지 않는다(PDF239·241).
- 본문 상품 합계330은 표시된 네 항목을 더한202와 다르다(PDF249). 프리미엄 상품128의 누락 가능성과 실제 합산을 구별한다.
- 성유물의 선택 가중치·변동 후 반올림, 일부 성장 테이블의 레벨 대응·보간은 원문만으로 완전 재현할 수 없다.

스킬은 이를 조용히 수정해 ‘책의 확정 정답’으로 만들지 않고, 원문 표기·정합 계산·프로젝트에서 정할 입력을 구별했다. 쪽수와 처리 규칙은 [원문 지도](../.agents/skills/game-balance-bible/references/source-map.md#추가로-확인한-원문-불일치와-적용-조건)에 있다.

## 확인 범위와 한계

주요 도식의 해석·입력/출력 관계와 실제 계산에 필요한 산식·대표값은 재확인했다. 모든 표의 모든 셀을 전사하거나 그래프의 모든 좌표를 복원한 작업은 아니다. 이 스킬은 원문을 재배포하는 데이터셋이 아니라 판단·계산·검증에 쓰는 합성 지식이다. 원문에 제시하지 않은 난수 가중치·반올림·현금흐름 등은 확인되지 않은 조건으로 남긴다.

과거 JSON 보고서는 당시 검사 범위의 기록이다. 원문 재확인 보고서의 파일 해시는 원문 대조 당시 스킬을 식별한다. 이후 실행 검산 지침을 보완한 스킬과 비교하면 해시가 달라질 수 있으며, 이를 원문을 다시 대조한 결과로 해석하지 않는다. 후속 변경과 해당 버전의 사용 시험·파일 해시는 [프롬프트 표본 검증 기록](../output/skill-review/prompt-sample-validation.json)의 `post_validation_refinement`에서 확인한다.
